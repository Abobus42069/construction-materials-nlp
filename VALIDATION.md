# Проверка версии 0.1.0

Проверено 15 ноября 2026 года на Windows, Python 3.13.

- 16 тестов пройдены: контексты температур, Unicode-минусы, границы, запреты, двойные отрицания, исключения, разрешения в нормативном тексте, источник, дубли и CLI.
- Обработан реальный экспорт парсера: 444 входные записи. Получено 215 аннотаций-кандидатов.
- Все цитаты проверены как точные срезы входного текста. Число аннотаций не означает число достоверных фактов: отдельные источники и повторные формулировки сохраняются независимо.
- Два документа с требованием OCR сохранены в отчёте.
- Синтетические примеры разработки проходят; независимая точность на реальном корпусе ещё не измерена.
- Отдельные нормативные строки могут обрываться на переносах: они отмечены для просмотра полного документа.
- CI для Windows/Linux и Python 3.10/3.13 подготовлен, но на GitHub ещё не запускался.

Следующая задача: ручная разметка реальных карточек и технических листов с независимой тестовой выборкой и отдельной оценкой ошибочных разрешений применения.
